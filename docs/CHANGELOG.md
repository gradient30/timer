# 更新日志

本文件记录 TimerApp 各版本的对外可见变更。格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循语义化版本。

## [0.1.4] - 2026-10-28

### 修复

- **点 X 收回托盘偶发无响应**（非必现，两个叠加原因）：
  - `CloseRequested` 处理器原先在主线程上等锁并同步写 `config.json`，写盘偶发变慢（杀毒实时扫描 / 磁盘繁忙）时窗口冻结数秒，表现为点 X 无反应。现改为**先隐藏窗口**（即时反馈），持久化移至后台线程执行（`lib.rs`）
  - 倒计时提前通知会从计时线程唤起主窗口（`show + set_focus`），与点 X 的 `hide` 跨线程竞速，窗口被"弹回来"。新增 `WindowHideGuard`：用户主动隐藏后 800ms 内抑制后台线程唤起窗口，通知事件仍照常发送（`lib.rs`、`notifier.rs`）
- 顺手修复 `startup.rs` 中新版 clippy（1.99）的 `needless_question_mark` 告警，保持 `-D warnings` 通过

### 新增

- `WindowHideGuard` 单元测试；关闭/通知链路补 `tracing::debug` 日志，便于后续诊断此类非必现问题
- 仓库根目录新增 `CLAUDE.md`（Claude Code 工作指引）；本更新日志文件

## [0.1.3] - 2026-08-19

### 新增

- 用餐/夜间休息时段（`quiet_hours`）：默认 12:00–13:00、18:00–19:00、00:00–09:00，半开区间。时段开始强制停止倒计时（可解锁、不再锁回），结束后重置并按主间隔自动开始工作倒计时；与循环番茄钟锁屏休息相互独立
- 设置页新增休息时段配置入口

### 变更

- 开机自启改用 HKCU Run 注册表（无需管理员权限），应用启动时按当前 exe 路径自愈写入，并清理旧版计划任务

## [0.1.2] - 2026-08-19

### 修复

- 开机自启不能稳定生效（`fix(startup)`）

## [0.1.1] - 2026-06-12

### 新增

- 主界面 v2：圆环倒计时、快捷预设、步进器微调与底栏主题/帮助/配置入口

## [0.1.0] - 2026-06-11

### 首发

- 定时提醒与系统动作：倒计时到点锁屏/关机，提前通知、有限次延后、循环休息
- 生效规则（时间段 + 星期）、系统托盘、开机自启
- 退出密码保护（argon2 + 安全问题找回 + safe_mode）
- 离线激活码体系（HMAC-SHA256）
- 深色 / 明亮 / 鲜艳三种界面风格
